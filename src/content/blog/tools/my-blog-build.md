其实一开始只是想找个地方放东西。

之前刷到一个 galgame 的博客，站长把自己的通关记录按角色路线整理，还有截图和碎碎念。我也想搞一个。《素晴日》的第三章我打了三遍，每次到那个天台场景都想写点什么，但手机备忘录里记了两行就再也接不下去。微博不行，朋友圈更不行，发出去我妈会问我“这是什么东西”。

于是决定搭博客。

技术这块其实不难，b 站教程一堆。Hexo 还是 WordPress 犹豫了半天，最后选了 Hexo + GitHub Pages，因为免费。对，就是免费。高三没什么钱，每个月话费都是我妈交的。本地环境折腾了一晚上，node 版本不对报错，换了个旧版本才行。那个晚上作业没写完，第二天地理小测炸了，32 分。然后晚上回来接着调主题配色。

选了一个很干净的主题，白底黑字，适合看文字。但其实我心里想要的是那种黑底、绿色字体、有点 terminal 风格的，只是没找到合适的。等高考完了自己改 CSS 吧，现在没时间。

域名没买，用的是 github.io 那个。本来想买 .im 结尾的，因为有一款叫《ATRI》的游戏，里面那个机器人就叫 Atri，如果域名是 atri.im 会很好看。但没钱。

搭好之后反而不知道写什么了。我本来想写很多关于视觉小说的东西，但对着空白的编辑器，感觉写什么都很假。后来想算了，就当日记本用。反正也没人看。

这里应该会乱一点。有时候是游戏感想，有时候是发泄，有时候可能就写一句“今天晚自习睡着了被班主任拍桌子吓醒”。无所谓了。

等下次模考完再来写吧。
