凌晨一点，我又在改 nginx 配置。

其实之前想过用现成的平台写，但那些编辑器加载太慢了。我们学校机房那破网，打开后台要等半分钟。后来看到 GitHub Pages 可以白嫖，就想着试试。

域名是阿里云买的，.top 后缀，第一年九块钱。DNS 解析那块卡了很久，CNAME 和 A 记录乱设，导致 www 和裸域一会儿能开一会儿不能。最后抄了篇教程才搞明白，www 要 CNAME 到 xxx.github.io，裸域要 A 记录指向四个 IP。

静态博客生成器用的 Hexo。装 Node.js 那步还算顺利，就是 npm 装依赖的时候老是断，换淘宝源折腾到十一点半。主题挑了个简单的，改了点 CSS，把链接颜色从蓝改成灰——太蓝了，像老师批作业的红笔。

主要是晚上回来搞。十点二十下晚自习，到家十点四十，洗个澡到十一点，然后开电脑。爸妈有时候会推门进来看看是不是在写题，我就把编辑器切到别的窗口，假装在做卷子。其实他们看不太懂黑色终端窗口上面滚的一行行字。

写得也不多，就几篇。部署倒挺快，hexo g 然后 hexo d，密码贴了五次。

最大的成就是 DNS 终于生效了。在教室用手机连校园网，能打开，虽然是 4G，加载三秒。挺蠢的，但还不错。

反正比刷题有意思一点。
